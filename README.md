# 🌦️ Weather App

A responsive web application that provides real-time weather updates with dynamic UI enhancements.

## 🚀 Features
- Search weather by city name  
- Displays temperature, humidity, and wind speed  
- Real-time data using OpenWeather API  
- Dynamic UI changes based on weather conditions  
- Error handling for invalid inputs  
- Responsive and user-friendly design  

## 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  
- OpenWeather API
